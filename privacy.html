Kaawen Confidentiality

How your information is handled

Kaawen is built around the idea that your birth data remains private. The reading is generated in your browser, and your personal chart details are not sent to a server for analysis.

  • Your birth date, birth time, and place are used only to generate your reading locally in the app.
  • If you turn on sync, we store only encrypted practice data that is not readable by us.
  • Analytics are limited to anonymous interaction counts and never include your chart content or identifying personal information.

PerTutto · Pinterest Integration

Privacy Policy

PerTutto Pinterest Integration · Last updated 3 August 2026 · a side ecommerce business under the same group as Kaawen

This policy describes how the PerTutto Pinterest Integration (the "Tool") handles data. The Tool is a private, single-operator utility that publishes product listings from the PerTutto Etsy shop to a Pinterest board owned by the same operator. It is operated by Yassin Lazar and is not offered to, installed by, or accessible to the public.

Who uses this Tool

The operator is the only user. The Tool authorizes against a single Pinterest account and a single Etsy shop, both owned by the operator. It has no user accounts, no sign-up, no multi-tenant access, and it does not act on behalf of any third party.

What data the Tool accesses

  • Etsy product listing data — listing titles, descriptions, product photographs, listing URLs and listing IDs from the operator's own shop. This is information already published publicly on Etsy.
  • Pinterest account and board data — the operator's own board identifiers and names, retrieved to determine where pins should be published.

The Tool does not access, collect, request or process personal data belonging to Etsy buyers, Pinterest users, site visitors, or any other individual. It reads no orders, no customer records, no messages, and no Pinterest user data beyond the operator's own account identifiers.

What the Tool stores

  • OAuth tokens for Etsy and Pinterest, stored in a local configuration file on the operator's own computer. Tokens are never transmitted to any third party, never displayed in full, and never committed to source control.
  • A local record of published pins — a file mapping Etsy listing IDs to the Pinterest pin IDs created from them, so the Tool does not create duplicate pins on repeat runs.

There is no server, no hosted database, and no cloud storage. All state remains on the operator's machine.

How the Tool authenticates

Access to the Pinterest API is obtained exclusively through Pinterest's OAuth 2.0 authorization flow. The operator is redirected to Pinterest, approves the requested scopes, and the resulting authorization code is exchanged for an access token. The Tool never collects, stores or transmits Pinterest login credentials, passwords, or session cookies.

The scopes requested are boards:read, boards:write, pins:read, pins:write and user_accounts:read — the minimum required to read the operator's boards and publish pins to them.

What the Tool shares

Nothing. No data is sold, rented, shared, transferred, or disclosed to any third party. There are no analytics, no advertising networks, no tracking pixels, and no third-party processors. The only external services contacted are the Etsy API and the Pinterest API themselves.

Data retention and deletion

Locally stored tokens and pin records persist until the operator deletes them, which can be done at any time by removing the Tool's configuration and state files. Pinterest access can be revoked at any time from Pinterest account settings, which immediately invalidates the Tool's tokens. Content published to Pinterest is governed by Pinterest's own policies and can be deleted directly from the Pinterest account.

Children

The Tool is not directed to children and processes no data from anyone other than its single operator.

Changes to this policy

If the Tool's data handling changes, this page will be updated and the date at the top of this section revised.
